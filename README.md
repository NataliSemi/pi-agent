# Pi Agent

A Raspberry Pi-based security and network monitoring agent.

## Features

- Network device scanning
- Unknown device detection
- Suricata alert monitoring
- DNS/device investigation tools
- Telegram command integration
- Security news digest generation

## Requirements

- Raspberry Pi
- Python 3
- Suricata
- Required Python packages from `secnews/requirements.txt`
