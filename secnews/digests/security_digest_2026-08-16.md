## New Evooo1Bot Linux botnet turns routers into traffic relay nodes

**Source:** BleepingComputer

**Published:** Sat, 15 Aug 2026 10:14:38 -0400

**Link:** https://www.bleepingcomputer.com/news/security/new-evooo1bot-linux-botnet-turns-routers-into-traffic-relay-nodes/

Relevance: High

Reason: This article discusses the Evooo1Bot Linux botnet, which is based on Mirai malware and targets internet-facing gateway devices. It includes features such as credential theft, SSH brute-forcing, DDoS attacks, and encrypted C2 communications, making it a significant threat to cybersecurity learners.

Summary:
- The Evooo1Bot malware turns routers into SOCKS5 traffic relay nodes.
- It extends Mirai's framework with capabilities like encrypted C2 communications, SSH brute-force scanner, and integrated exploit arsenal targeting multiple vulnerabilities.
- Some exploits are not correctly implemented, leading to failed exploitation attempts.
