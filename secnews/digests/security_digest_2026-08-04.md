## New Pass-ta-key attacks let malware hijack Google-synced passkeys

**Source:** BleepingComputer

**Published:** Mon, 03 Aug 2026 19:58:01 -0400

**Link:** https://www.bleepingcomputer.com/news/security/new-pass-ta-key-attacks-let-malware-hijack-google-synced-passkeys/

**Relevance: High**

**Reason:** These attacks highlight significant vulnerabilities in the implementation of passkeys and Google's cloud authenticator, which could be exploited by attackers to compromise user accounts without requiring additional credentials. This is particularly concerning for users who rely on passkeys for secure authentication.

**Summary:**
- **Bullet 1**: The "Pass-ta-key" attack allows malware running on a compromised device to impersonate the victim's trusted computer and request valid authentication responses from Google.
- **Bullet 2**: Malware can sign these requests without needing administrator privileges, user interaction, biometrics, or even unlocking the device. This bypasses standard security measures that prevent passkey theft through phishing or other means.
- **Bullet 3**: The attack works by exploiting weaknesses in how Chrome and Google's cloud authenticator handle device trust, onboarding, recovery, and synced credentials.

**Security+ domain: Threats, Vulnerabilities, and Mitigations**

**Key terms:**
- TPM (Trusted Platform Module)
- Passkeys
- User Verified flag

**Defensive lesson:**
- Users should be cautious about clicking on suspicious links or downloading unknown files that could potentially install malware. Additionally, they should enable two-factor authentication whenever possible to add an extra layer of security.
