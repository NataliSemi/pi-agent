## Google Chrome may soon block New Tab hijacker extensions by default

**Source:** BleepingComputer

**Published:** Sun, 02 Aug 2026 10:17:16 -0400

**Link:** https://www.bleepingcomputer.com/news/google/google-chrome-may-soon-block-new-tab-hijacker-extensions-by-default/

**Relevance: High**

**Reason:** This article discusses a significant security feature that Google is developing for Chrome, which could potentially protect users from malicious extensions hijacking the New Tab page and changing their default search engine. This feature addresses a common vulnerability in web browsers where unauthorized extensions can be installed to manipulate user interface elements or change settings without permission.

**Summary:**
- **Bullet 1:** Google plans to enable a new security feature that blocks policy-installed extensions from hijacking the New Tab page.
- **Bullet 2:** The proposed protection flag, `kBlockDseNtpOverrideExtensionsOnUnmanagedDevices`, will default on unmanaged Windows and macOS devices.
- **Bullet 3:** This change aims to prevent malware from abusing enterprise policies to install unauthorized extensions that could alter user interface elements or redirect searches.

**Security+ Domain:**
1. General Security Concepts

**Key Terms:**
- Policy-installed extensions
- New Tab page hijackers
- Managed by your organization message

**Defensive Lesson:**
- **Practical Defensive Takeaway:** Users should be cautious of extensions that claim to enhance security or privacy features, as they might be maliciously installed under the guise of legitimate software.

## COLDCARD wallet RNG flaw likely linked to $88 million Bitcoin theft

**Source:** BleepingComputer

**Published:** Sun, 02 Aug 2026 17:14:29 -0400

**Link:** https://www.bleepingcomputer.com/news/security/coldcard-wallet-rng-flaw-likely-linked-to-88-million-bitcoin-theft/

**Relevance: High**

**Reason:** This article highlights a significant security vulnerability in hardware wallets, specifically the COLDCARD wallet, which could have been exploited to steal millions of dollars worth of Bitcoin. The flaw is related to the random number generator (RNG) used by the device, and it demonstrates how software vulnerabilities can be leveraged to compromise cryptographic systems.

**Summary:**
- **Bullet 1:** Researchers suspect a vulnerability in COLDCARD hardware wallet firmware was exploited.
- **Bullet 2:** An estimated $88.6 million worth of Bitcoin was stolen from thousands of wallets using a flawed RNG.
- **Bullet 3:** The attack occurred approximately 30 hours before Coinkite publicly disclosed the flaw, indicating a potential delay in detection.

**Security+ domain: Threats, Vulnerabilities, and Mitigations**

**Key terms:**
- Random Number Generator (RNG)
- Hardware Wallet
- Software Exploit

**Defensive lesson:**
- **Practical Defensive Takeaway:** Always ensure that software components used within hardware devices are secure. This includes verifying firmware updates and regularly testing for vulnerabilities in the device's underlying code.
