## Hackers breach TrueConf to trojanize client installers with backdoors

**Source:** BleepingComputer

**Published:** Sat, 08 Aug 2026 10:16:23 -0400

**Link:** https://www.bleepingcomputer.com/news/security/hackers-breach-trueconf-to-trojanize-client-installers-with-backdoors/

**Relevance: High**

**Reason:** This article highlights the significant cybersecurity risks posed by unpatched software vulnerabilities, specifically in TrueConf video conferencing servers. The exploit leverages default open ports and internal tracking numbers to deliver malicious backdoors, demonstrating how attackers can bypass security measures to gain unauthorized access and deploy harmful software.

**Summary:**
- **Bullet 1:** Head Mare hacktivists exploited unpatched TrueConf servers to replace client installers with malicious versions that included PhantomCore and PhantomGraph backdoors.
- **Bullet 2:** The attack used a web shell to collect sensitive information, gain remote access, and deploy trojanized installation packages for potential victims.
- **Bullet 3:** The compromised server replaced the legitimate TrueConf Client installer with a malicious version containing the PhantomCore backdoor.

**Security+ Domain: Threats, Vulnerabilities, and Mitigations**

**Key Terms:**
- Head Mare
- TrueConf
- PhantomCore
- PhantomGraph

**Defensive Lesson:**
- Implement regular software updates to patch known vulnerabilities.
- Use strong authentication methods for accessing server environments.
- Conduct thorough security audits and penetration testing.
